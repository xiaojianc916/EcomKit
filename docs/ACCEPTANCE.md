## 只能人工验证的（写进交付说明）

| # | 验收项 | 为什么自动不了 | 怎么做 |
| --- | --- | --- | --- |
| M1 | 第一次点下载弹出授权小窗，选完目录**自动开始下载** | 系统目录选择对话框无法自动化 | 手动装扩展，点一次下载，选目录，观察是否自动开始 |
| M2 | 直接关掉小窗时主按钮恢复原状 | 同上 | 点下载 → 弹出小窗 → 直接关掉 → 看主按钮 |
| M3 | 浏览器重启后最多点一次授权；选「每次访问时允许」后不再询问 | 需要真实重启浏览器 + 用户手势 | 按方案 §17-1 走一遍，Chrome 和 Edge 各一次 |
| M4 | 下载 500MB 视频时内存平稳 | 需要真实大文件 | 任务管理器看扩展进程内存曲线 |
| M5 | Chrome 和 Edge、Win10 和 Win11、缩放 100%/125%/150% | 需要多环境 | 按方案 §19 第 14 条逐项过 |
| M6 | 真实拼多多页（已登录）/ 真实抖音页 | 平台需要登录态，抖音桌面端被限制 | 用已登录的日常浏览器加载扩展实测 |
